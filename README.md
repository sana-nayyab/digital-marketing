## ⚡ Quick Deploy (90 seconds)

### 1️⃣ Create GitHub Repo
- Go to [github.com/new](https://github.com/new)
- Name it: `your-username.github.io`
- Make it Public
- Create

### 2️⃣ Upload Files
```bash
git clone https://github.com/your-username/your-username.github.io.git
cd your-username.github.io
# Copy all files here
git add .
git commit -m "Add portfolio"
git push
```

### 3️⃣ Done! 🎉
Visit: `https://your-username.github.io`

## 🔗 Contact Form Setup (Optional)

To make the contact form work:

1. Go to [Formspree.io](https://formspree.io)
2. Sign up free
3. Create a form for your email
4. Copy the form endpoint
5. In `contact/index.html`, find:
   ```html
   action="https://formspree.io/f/YOUR_FORM_ID"
   ```
6. Replace with your Formspree ID
7. Test the form!

## 🌐 Custom Domain

Want `sananayyab.com` instead of `username.github.io`?

1. Buy domain from GoDaddy, Namecheap, etc.
2. Go to repo **Settings** → **Pages**
3. Add custom domain
4. Update domain's DNS records (follow GitHub guide)
5. Done!
